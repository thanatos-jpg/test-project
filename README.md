# 世界ごはん制覇

毎月食べた世界の料理を記録して、195か国の制覇を目指すスマホ向けWebアプリ（PWA）です。
サーバー不要・データは端末のブラウザ内（IndexedDB）に保存されます。

## 機能
- 国・料理名（複数可）・料理の写真・レストラン・日付・地図リンク・参加者・評価・メモの記録
- 国旗ギャラリー（地域でグループ化／絞り込み、並び替え）
- 制覇進捗（全体・地域別）、世界地図（食べた国を色分け、ピンチ拡大）、未制覇リスト、ルーレット
- 履歴（開催順・月別・第N回）
- バックアップの書き出し／読み込み（JSON、写真込み）
- オフライン動作・ホーム画面に追加

## 使い方
静的ファイルだけなので、どこでも配信できます（HTTPS推奨。GitHub Pagesなど）。
ローカルで試す場合：

```sh
python3 -m http.server 8000   # → http://localhost:8000
```

## 構成
| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面とロジック |
| `db.js` | 保存層（`window.Store`）。クラウド保存へ移行する場合はここを差し替える |
| `countries.js` | 195か国のデータ（国名・地域） |
| `map-data.js` | 軽量化した世界地図（`tools/build-map.js` で生成） |
| `sw.js` / `manifest.webmanifest` | オフライン対応・PWA設定 |
